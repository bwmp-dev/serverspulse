# Security Policy

## Supported versions

Security updates are provided for the latest released agent version. Older
versions and unreleased development snapshots are not supported. If a fix can
be applied safely to another maintained release line, the maintainers may do so,
but no backport is guaranteed.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |
| Development snapshots | No |

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for security issues. Include
the affected agent version, server platform, Minecraft version, and reproduction
steps where possible.

Do not include API keys, registration codes, server addresses, or customer data
in a public issue.

If private vulnerability reporting is unavailable, contact the project
maintainers through the support channel at https://serverspulse.com and request
a private security contact. Do not send exploit details through a public issue.
